Support

Found a problem, a document that doesn't open or looks wrong, or have an idea? Write to aderby3d@gmail.com. If a particular file misbehaves, please mention where it comes from (or attach it, if it can be shared) and your macOS version.

Vulite requires macOS 14 Sonoma or later and runs natively on Apple silicon and Intel Macs.

Questions

Vulite asks for access to a folder. Why?

Some DjVu documents are stored as several files: a small index file and a file per page, all in one folder. macOS lets an app read only the file you opened, so Vulite asks you once to choose that folder. The permission is remembered; you can remove the app's permissions by deleting the app.

How do I zoom?

Pinch on the trackpad, hold ⌘ and scroll, or use ⌘+ and ⌘−. The toolbar buttons fit the page width or the whole page.

Can I search and copy text?

Yes, if the document has a text layer (most scanned books with recognized text do). Use the search field in the toolbar; select text with the mouse and press ⌘C.

How do I read at night?

Choose the night or sepia theme with the theme button in the toolbar. Photos and illustrations keep their colours.

Can I convert DjVu to PDF?

Yes: File ▸ Export as PDF… (⇧⌘E). You can export all pages, the current page or a range; the PDF keeps an invisible text layer, so it stays searchable.

Does Vulite send my documents anywhere?

No. Vulite works entirely offline and collects no data. See the Privacy Policy.

Вопросы

Vulite просит доступ к папке. Зачем?

Некоторые документы DjVu хранятся в нескольких файлах: небольшой файл-оглавление и по файлу на страницу, все в одной папке. macOS разрешает приложению читать только открытый файл, поэтому Vulite один раз просит выбрать эту папку. Разрешение запоминается; удалить разрешения приложения можно, удалив приложение.

Как менять масштаб?

Щипком на трекпаде, прокруткой с зажатой ⌘ или клавишами ⌘+ и ⌘−. Кнопки на панели вписывают страницу по ширине или целиком.

Можно ли искать и копировать текст?

Да, если в документе есть текстовый слой (он есть у большинства сканов с распознанным текстом). Ищите через поле поиска на панели; выделите текст мышью и нажмите ⌘C.

Как читать ночью?

Выберите ночную тему или сепию кнопкой тем на панели. Фотографии и иллюстрации сохраняют свои цвета.

Можно ли перевести DjVu в PDF?

Да: Файл ▸ Экспортировать как PDF… (⇧⌘E). Можно выгрузить все страницы, текущую или диапазон; в PDF остаётся невидимый текстовый слой, и по нему работает поиск.

Отправляет ли Vulite мои документы куда-нибудь?

Нет. Vulite работает полностью без интернета и не собирает данные. Подробнее — в политике конфиденциальности.
